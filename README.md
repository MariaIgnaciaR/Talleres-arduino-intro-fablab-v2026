# 🔌 Introducción a Arduino — FabLab.UV

Taller práctico de introducción a Arduino y electrónica básica, dictado por FabLab.UV, Universidad de Valparaíso. Dirigido a estudiantes universitarios sin experiencia previa en programación ni electrónica.

## 📅 Estructura del taller

El taller se divide en **3 sesiones de 1.5 horas** cada una:

| Sesión | Contenido |
|--------|-----------|
| **Sesión 1** | Fundamentos de Arduino, IDE, variables, entradas/salidas digitales, circuito LED y semáforo |
| **Sesión 2** | Señales analógicas, PWM, sensores (LDR, potenciómetro), comunicación serial |
| **Sesión 3** | Servomotores, buzzers, botones, y proyecto final integrador |

## 🎯 Objetivos de aprendizaje

- Comprender la diferencia entre hardware y software en un sistema embebido
- Programar en el lenguaje de Arduino (basado en C++)
- Armar circuitos electrónicos básicos (LEDs, sensores, actuadores)
- Leer y procesar señales digitales y analógicas
- Aplicar lógica de programación (condicionales, funciones, control de tiempo)
- Desarrollar un proyecto propio combinando lo aprendido

## 🛠️ Materiales requeridos

- Arduino UNO
- Cable USB
- Protoboard
- LEDs (rojo, amarillo, verde)
- Resistencias 220-330 Ω
- Potenciómetro
- LDR (fotoresistencia)
- Botón/pulsador
- Buzzer
- Servomotor
- Cables jumper

## 💻 Software

- [Arduino IDE](https://www.arduino.cc/en/software) (instalación local)
- [TinkerCad Circuits](https://www.tinkercad.com/) (simulador online, usado para demostraciones)

## 🚀 Cómo usar este repositorio

1. Clona el repositorio:
```bash
   git clone https://github.com/tu-usuario/introduccion-arduino-fablab.git
```
2. Abre el archivo `.ino` correspondiente en Arduino IDE
3. Conecta tu Arduino UNO por USB
4. Selecciona la placa y el puerto correcto en **Herramientas**
5. Sube el código con el botón de verificar/subir

## 🎓 Proyecto final

Al finalizar el taller, cada estudiante/grupo elige uno de los siguientes proyectos para implementar de forma autónoma:

- **Combo 1 – Alarma:** LDR + Buzzer (suena cuando oscurece)
- **Combo 2 – Semáforo peatonal:** 3 LEDs + Botón
- **Combo 3 – Control manual:** Servo + Potenciómetro
